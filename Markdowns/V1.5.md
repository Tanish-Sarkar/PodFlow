**AI Evaluation Layer (your strongest differentiator):**

**Landing page:**

- No backend dependency, just routing

**Unchanged from V1:**
- LangGraph + MemorySaver, FastAPI, React/Vite, Gemini, Gmail OAuth send, double HITL pattern

## On login/OAuth — do you need it?

**No, not for this stage.** Here's the actual reasoning:

- Your **Gmail OAuth for sending email** is functionally required — that's not optional, it's how the dispatcher works.
- A **user login/account system** (Clerk, sign-up/sign-in, sessions) is a different thing entirely, and you don't need it yet:
  - You're not storing per-user history, subscriber lists, or multi-tenant data in V1.5
  - A founder watching a demo doesn't care if there's a login wall — they care if the agent pipeline works
  - Adding auth now means building session management, protected routes, and user state for a single-user demo — pure overhead with zero signal
  - It's also one of the most "templated tutorial" things you can add — it doesn't differentiate you
